# US ZIP coordinates

Derived from GeoNames US postal-code data: https://download.geonames.org/export/zip/US.zip
Source: https://www.geonames.org/
License: Creative Commons Attribution 4.0, https://creativecommons.org/licenses/by/4.0/
Downloaded 2026-10-28. Converted the first location for each ZIP to [latitude, longitude, city, state].
ZIP+4 uses its first five digits. Coordinates approximate ZIP locations, not street addresses; distances are straight-line miles, not driving distances. Missing ZIPs have unknown distance.
